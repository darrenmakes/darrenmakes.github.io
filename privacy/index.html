Privacy

What this site does with your numbers

Cogspan does not ask for a name, an email, or an account. The gear chart is calculated in your browser. This page describes the first version of the site, published October 7, 2026.

Calculations stay here

Chainrings, cogs, wheel size, cadence, and an optional crank length are read by a script that ships with the page. They are not posted to a Cogspan server, because there is no calculator server. Copying the chart or the link uses your browser’s clipboard and, for the link, the address bar. A shared link contains the tooth counts and wheel size you put in it, because that is the chart. Do not put anything private in those fields. They are for gears.

Local storage on this device

After you edit the form, the page may save the last wheel, tooth counts, cadence, speed unit, tire factor, measured rollout, and crank length under the key cogspan.v1 in this browser’s local storage. That is so the chart is still there when you come back. It is not sent to Cogspan. Reset on the calculator clears it. You can also clear site data in the browser. If local storage is blocked, the calculator still runs and simply forgets the chart when you leave.

A link that already contains those values (anything after the ? in the address) is used instead of the saved chart, so a shared example does not get overwritten by an older visit.

No third-party scripts

Pages load the site’s own HTML, CSS, and JavaScript, plus the favicon. Fonts are the ones already on your device. There is no analytics tag, no advertising network, and no social pixel. An HTML comment in each page marks where a privacy-respecting analytics snippet could go later. Nothing is there now.

The only outbound link on the site is the about page’s reference to Sheldon Brown’s gear calculator, and it loads only if you choose to open it.

Ads and affiliate links

The dashed box on the homepage is a placeholder. It does not contact an ad network and it does not contain a shop link. If an affiliate or ad placement is added later, this page will name the provider before that script or image is allowed to load.

Hosting logs

Cogspan’s files do not record visitors. Whoever hosts the static files may keep ordinary server logs, such as IP address, time, and the URL requested, as part of running a web server. That is the host’s logging, not a Cogspan account. The canonical host written into these pages is darrenanderson94.github.io. If the files are served from a different domain, that host’s policy applies to the connection.

Children

The calculator is a bicycle gear chart. It is not directed at children, and it does not knowingly collect personal information from anyone.
